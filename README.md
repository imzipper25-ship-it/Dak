# OBRA TRANSPARENTE — Landing Page para Construção Civil em Portugal

Лендинг для португальской строительной компании, выполненный в стиле **Swiss Design Minimalism**.

## 🛠 Технологии и Стек
- **HTML5 & CSS3** (Vanilla CSS с поддержкой кастомных переменных, Flexbox и CSS Grid)
- **JavaScript (ES6+)** (Управление модальными окнами, логика прокрутки, плавные анимации)
- **Google Fonts**: `Syne` (акцентные заголовки) и `Plus Jakarta Sans` (основной текст)
- **High-contrast Swiss Design**: крупные жирные шрифты, формы с закруглениями 24px, плавающие glassmorphism-карточки

## 📱 Блоки лендинга
1. **Header**: Логотип, навигация, кнопка вызова формы расчёта.
2. **Hero Section**: Полноэкранный кинематографичный визуал строительного объекта, заголовок *CONSTRUÍMOS COM TRANSPARÊNCIA*, интерактивные плавающие карточки.
3. **Benefícios (✦ PORQUÊ NÓS)**: Описание работы по модели *à jorna*, блоки с метриками и гарантиями.
4. **Serviços (✦ A NOSSA EXPERIÊNCIA)**: Визуальный баннер с перечислением услуг (*Construção de Raiz*, *Remodelações*).
5. **Como Funciona (✦ COMO FUNCIONA)**: 3-х шаговый прозрачный процесс от консультации до сдачи объекта.
6. **Footer & Modal**: Форма обратной связи и прямой связи с командой.

## 🚀 Локальный запуск
Для запуска локального сервера разработки:
```bash
npx serve -l 3000
```
Сайт будет доступен по адресу `http://localhost:3000`.
